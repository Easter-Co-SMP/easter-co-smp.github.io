Before you set sail

Make yourself at home.

This is a private server. An existing member can help you get access and share the connection details.

  1. Start with Fabric.Use a separate Minecraft profile. The matching version and Fabric Loader are required.
  2. Add the server’s mods.Download Easter Co.’s custom mod, then install the required dependencies below. Ask your inviter for the full matching client setup.
  3. Meet us on the Isles.Close and reopen the game after installing mods. Connect using your invitation, and accept the server resource pack.
Required dependencies
  • Fabric API
  • Shippy Ships
  • IngeniumAPI
  • Tectonic
  • Lithostitched

Third-party mods come from their original publishers. Back up your existing mods folder before changing it. This server is not affiliated with Mojang or Microsoft.
