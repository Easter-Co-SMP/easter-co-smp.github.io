# Launcher app icon

`desktop/launcher-icon.png` is the launcher-specific 512 × 512 RGBA icon. Linux and Windows packaging and the Electron window use this asset. The website favicon and community crest are separate assets. The Linux desktop filename, Electron app ID and StartupWMClass use `easter-company` so desktop environments can associate the running window with its launcher icon.

Created with the built-in image-generation tool, then mechanically resized from the generated source to the packaging size with Lanczos resampling.

## Generation prompt

Create one polished production app icon for Easter Co. Launcher, a nautical Minecraft community launcher. A bold, distinctive warm-gold compass emblem with a single right-facing launch triangle cut into its center, balanced and simple enough to recognize at 16–32 pixels. Deep midnight teal rounded-square tile, restrained soft bevel and subtle depth, crisp geometric silhouette, generous safe margins. Gold compass points evoke navigation and embarking on an adventure; keep only a few strong shapes. Premium desktop application icon, clean and purposeful. No lettering, no words, no badges, no surrounding mockup, no Minecraft blocks, no busy illustration. Square composition, transparent outside the rounded tile, high resolution.
