# Easter Company launcher 1.0.15

Easter Company is now your primary account, with a unique Microsoft/Xbox link.

- **Login with Microsoft Account** signs you in or creates your Easter Company account from the available Minecraft profile. Registration also works without Java ownership.
- New accounts choose their Easter Company username first and then their password to finish setup. The username is unique, it cannot be changed later, and it is what you sign in with; a password change never asks for it again. There is no Company ID to remember.
- Sign in directly with your username or email and password. Minecraft still requires the linked Microsoft account and valid Java access.
- Reset your password through your linked Microsoft identity. Reset revokes previous Company sessions.
- Minecraft starts fullscreen with a GUI scale chosen for your primary display: 2 on ordinary screens, 3 on 1440p-class screens and 4 on 4K, reduced when needed to fit. This also sets up an already-installed client once; later changes made in Minecraft are preserved. These defaults work with Enhanced Graphics on or off.
- The installed client is set up with the household's controls: crouch on Left Ctrl and sprint on Left Shift (the default pair swapped), inventory on Tab, the player list on the tilde key, third person on R, chat on Enter, the GUI toggle on F10, the social screen on I, and smooth camera on Right Shift. Shippy Ships' Quick Build moves off Left Ctrl to Right Ctrl so crouch owns Ctrl; the Easter Navy crew menu opens with the player list, so it moves to tilde too. The F3 debug keys are unbound in a seeded client, so the debug overlay and its combinations are off. Like the display settings, this happens once and any change you make in Minecraft afterwards is kept.
- The launcher no longer closes when the game starts: it stays where it is, unless you choose one of two linked alternatives in Settings, which cannot both be on. **Close launcher when the game starts** closes it behind the game as before; **Minimise launcher to the system tray when the game starts** steps it aside instead and brings the window back when Minecraft exits. On a desktop with no system tray, the launcher still steps aside and a sentence tells you to start the launcher again to bring the window back. The old close-on-launch default is reset once on update so this change actually reaches you; after that your own choice sticks.
- Settings can create a **desktop shortcut** and a **Start menu entry** for the game. Both start Easter Co. Launcher, which checks for and applies the mandatory launcher and client updates exactly as pressing Play does, then opens the game and honours whichever launch behaviour you chose. They are off by default, removed when you untick them, and should you remove them by hand the launcher says so instead of pretending they are there. The launcher's own uninstallers do not remove these two entries, so untick them first if you want them gone.
- A distinct gold compass and launch-symbol app icon identifies the launcher in windows, desktop shortcuts and Linux/Windows installers.
- The profile menu leads with your Easter Company username. Cancellation, failed login and conflicting Microsoft identities preserve the active account.
- The backend stores unique provider links so another verified provider, such as Steam, can be added later.

Validation covers Node and Python unit tests, migrations and real PostgreSQL transactions, a full Electron journey through the real API handler with a synthetic provider, existing launcher/browser/map/wiki/update checks, visual review and packaged-bundle verification. Cases include profile-less registration, required setup, wrong passwords, conflicting links, legacy ID migration, concurrent signup, password reset/revocation and no credentials in renderer state. No real Microsoft account authentication, password changes or game launches were performed during fixture testing. This host's unavailable OS keyring exercises the secure-vault refusal path.

The required updater delivers this release automatically to 1.0.11 and later. Users on 1.0.10 or earlier need the bootstrap installer once. Installers are unsigned; SHA256SUMS covers all installers and updater assets.
